# Part 3: Build A Chat UI

## Task

Build a polished chat interface with basic frontend logic for a secure chat application.

You do not need a real backend. Use local state and mock data.

## Required UI

Your interface should include:

- Conversation list
- Active conversation header
- Message list
- Message composer
- Sending, sent, and failed message states
- Online/offline indicator
- Empty state for a conversation with no messages

## Required Logic

Your implementation should support:

- Selecting a conversation
- Sending a new message
- Showing a temporary `sending` state
- Marking the message as `sent` after a short delay
- Simulating a failed send for at least one case

## Notes

You can use React, Angular, Vue, or plain TypeScript/JavaScript.

Prioritize clarity, maintainability, and a usable interface over visual complexity.

Be ready to explain your component structure and state model.
